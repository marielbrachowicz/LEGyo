## Requisitos para trabajar en el proyecto

> ⚠️ **Obligatorio:** hay que tener la carpeta **`01_Referencia_MiembroSuperior`** (el proyecto Unity del brazo, unos 3,3 GB).
> No está en GitHub porque pesa demasiado; se comparte aparte (USB o Drive).
> Hay que copiarla **en la raíz de este repositorio**, con ese nombre exacto. Git la ignora, así que no se sube.

```
LEGyo/
├── 01_Referencia_MiembroSuperior/   ← copiar a mano (no está en GitHub)
├── 03_Unity_MiembroInferior/        ← proyecto Unity (se abre con Unity 2022.3.62f3)
├── 00_Documentacion/
└── LEEME.md                         ← guía completa: instalación, estado y próximos pasos
```

Además: **Unity 2022.3.62f3**, **Kinect for Windows SDK 2.0** y un **Kinect v2** con su adaptador para PC.

👉 Instrucciones completas en [LEEME.md](LEEME.md).
